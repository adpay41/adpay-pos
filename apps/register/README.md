# @adpay/register

React Native Android register app. Runs as Device Owner in lock-task (kiosk) mode and as the HOME launcher. Dual-screen: merchant display + customer display via the Android Presentation API. Offline-first — SQLite on device is the source of truth. Build sequencing step 2.

Empty scaffold. See [`docs/spec-v1-cstore.md`](../../docs/spec-v1-cstore.md) for scope and
[`CLAUDE.md`](../../CLAUDE.md) for the fixed decisions and build sequencing.
